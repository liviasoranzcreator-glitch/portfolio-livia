# Livia Cardoso — Portfólio

Portfólio pessoal de Livia Cardoso, estudante de Administração na PUC-Campinas, construído para o processo AI Builder. O site reúne projetos de IA, dados e produto em uma página única, com visual inspirado no Ramp Design.

## O que tem no site

- **Abertura:** os projetos entram voando em 3D como telas das apresentações. Clicar abre a apresentação completa.
- **Sobre mim:** resumo, prêmios e contatos (LinkedIn, e-mail, telefone), com link para o currículo.
- **Por onde ando:** fotos de eventos, palcos e hackathons espalhadas pela tela, com navegação foto a foto.
- **O que construo:** grade com RankUP, Aresta, BEES PRO, Ecologic, Vênus e o artigo sobre poder na rede de IA. Cada projeto abre os slides, a stack e as habilidades desenvolvidas.

## Estrutura

```
index.html      página única (HTML, CSS e JS inline)
curriculo-livia-cardoso.pdf  currículo
img/            slides dos projetos, fotos e imagens
vercel.json     configuração de deploy
```

## Rodar localmente

Abra o `index.html` com um servidor estático. Por exemplo:

```
npx serve .
```

## Deploy

Hospedado na Vercel. Cada push na branch `main` gera um novo deploy no mesmo endereço.
